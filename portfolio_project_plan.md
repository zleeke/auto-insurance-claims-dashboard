# Portfolio Project Plan

## Goal
Create a data analytics portfolio project that can be shared on LinkedIn and shown to employers. The first project should be a simple Python dashboard that is easy to build, visually appealing, and free to host online.

## Recommended stack
- Python for analysis and dashboard logic
- Streamlit for the web dashboard
- Plotly for interactive charts
- Pandas for data handling
- GitHub for version control
- Streamlit Community Cloud for free hosting

These tools are beginner-friendly and work well on a Mac.

## Recommended project approach
1. Choose one clear dataset with a simple story.
   - 
2. Build a small MVP dashboard with:
   - 3 to 5 charts
   - a few KPI cards
   - one or two filters
   - a short title and summary
3. Publish the project on GitHub.
4. Deploy it for free using Streamlit Community Cloud.
5. Share the live link on LinkedIn with a short explanation of the work.

## Good first project ideas
- Sales or marketing dashboard
- Real estate or housing analysis
- Movie, music, or app usage dashboard
- Public health or finance dataset

## Suggested next steps
1. Pick one dataset and define the main question the dashboard answers.
2. Create a new folder in VS Code for the project.
3. Set up a Python virtual environment on your Mac.
4. Install the core packages:
   - python3 -m venv .venv
   - source .venv/bin/activate
   - pip install streamlit pandas plotly
5. Build a basic dashboard with a few charts and metrics.
6. Add a README file with project description, setup instructions, and deployment notes.
7. Push the project to GitHub.
8. Deploy it through Streamlit Community Cloud.

## What to include in the final portfolio item
- A clear title
- A short summary of the business question
- Key insights from the data
- Interactive visuals
- A live link
- A short note on tools used

## LinkedIn post idea
Share a short post that explains:
- what problem the dashboard addresses
- what tools were used
- what insights it highlights
- the live link to view it

## Priority recommendation
Start simple. Build one polished, interactive dashboard that demonstrates data cleaning, analysis, and visualization rather than trying to build a large project too early.
